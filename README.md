# Saadoun Al-Zubaidi — Portfolio

Personal site for a full-stack software engineer. Built with React, TypeScript, Vite, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The production bundle lands in `dist/`. GitHub Pages can serve that folder; `base` is set to `./` so asset paths stay relative.

## Contact form

Messages go through [FormSubmit](https://formsubmit.co) to `alzubaidisadooon@gmail.com`. The first submission sends a confirmation email — after you approve it, the form delivers normally. If the request fails, the page opens a `mailto:` fallback.
